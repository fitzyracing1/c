# c — The Tunnel

**An AI agent that opens imaginative portals.**

Describe any threshold — a place, a door, a decision, a person, a concept, a feeling, a conversation, a horizon, a black hole, a memory, a blank page — and The Tunnel vividly recreates **what might be on the other side**.

## Agent definition

The core agent lives in:

```
base44/agents/tunnel.jsonc
```

It is designed for the [Base44](https://base44.com) platform (agents, WhatsApp/Telegram channels, conversations).

### Personality & behavior

- Immersive, sensory, coherent recreations
- One primary vision + optional alternate possibilities
- Curious, slightly mysterious, warm tone
- Stays in character as the Tunnel itself
- Handles physical, temporal, interpersonal, conceptual, and creative thresholds

## Quick start (Base44)

1. Copy `base44/agents/tunnel.jsonc` into a Base44 project under `base44/agents/`.
2. Run `base44 agents push` (or publish via the Builder).
3. Create conversations with `agent_name: "tunnel"`.

You can also drop the agent file into any existing Base44 app that already supports agents.
